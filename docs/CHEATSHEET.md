# Daurade: quick cheat sheet

What every control does, by what you want to do. The [manual](MANUAL.md) goes through every page.

**Getting around:** KNOB 1 to 4 turn the four cards on the screen. A page's button opens it; pressed again, its
second page where it has one. HOME takes you back to PLAY. The keys only ever play music.

## Play

| What | How |
| --- | --- |
| Start / stop | **PLAY**: with the intro (ARC on) |
| Tempo / volume | **SELECT** / **MASTER** |
| Another style | **PRESETS**: one of ten, on the next bar line (CHROME: FILTER HOUSE, ROBOT POP, SHRED, NIGHT DRIVE, SLOW JAM; SESSION: DISCO, SEQUENCER, FUNK, BALLAD, FINALE) |
| Another song | **ALGORITHM**: a new chord loop, bass line and hook in the same style, on the next bar |
| Drop it | **REC**: tapped, all but the filtered loop out for two bars; held, out until you let go |
| A solo | **SEQ**: from the next beat, for SOLO's bars; again, it stops |
| Play the lead | **Keys**: as you press them; hold **HOME**, KNOB 3: **SNAP** on, snapped to the scale. **OCT-** / **OCT+**: their octave |

## The four knobs (PLAY)

| What | How |
| --- | --- |
| The filter | KNOB 1: **SWEEP**, the ceiling it breathes up to over sixteen bars |
| The pump | KNOB 2: **PUMP**, how deep the mix ducks on each kick |
| The robot | KNOB 3: **VOICE**, off, the hook every second half of eight bars, or all the way |
| Busier | KNOB 4: **ENERGY**, ghost notes, sixteenth hats, extra chops |

## Sound

| What | How |
| --- | --- |
| The parts' sounds | **FX**: **STABS**, **BASS**, **LEAD** (ten each), **DRUMS** (CRISP, SESSION, MACHINE) |
| Tone | **FX** again: **RESO**, **DRIVE**, **PHASER**, **CRUSH** |
| The robot's voice | **LFO**: **VOWELS**, **SHIFT**, **TALK**, **GLIDE** |
| Drums | **EDIT**: **KIT**, **KICK** (PUNCH, ROUND), **SNARE** (CLAP, SNARE, BOTH), **SNAP** |
| Levels | **GLO**: the four parts |
| Room | **GLO** again: **REVERB**, **DELAY**, **TIME**, **WIDTH** |

## The music

| What | How |
| --- | --- |
| Key and chords | **SCL**: **KEY**, **SCALE**, **CHORDS** (twelve loops), **BARS** a chord |
| Groove | **ARP**: **SWING**, **HUMAN**, **HATS**, **FILLS** |
| The song's shape | **ENV**: **ARC** (intro, main, build, drop, solo, breakdown), **BUILD**, **DROP** AUTO, **SOLO** AUTO |
| The solo | **SEQ**'s page: **SPEED**, **BEND**, **RANGE**, **BARS** |

## Keep and connect

| What | How |
| --- | --- |
| Sets | **SAVE**: eight sets. **SET** picks, **LOAD** / **STORE** turned right, **CLEAR** turned right three times |
| Colour, CPU | Hold **HOME**: MENU, **COLOR**, **LOOK**, **SNAP** (the keys onto the scale) |
| MIDI out | STABS on channel 1, BASS 2, LEAD 3, drums 10 |
| Saving | Automatic, while stopped |
